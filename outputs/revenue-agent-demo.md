## 5-Email Follow-Up Sequence

1. **Delivery** — *"Here's your Revenue Agent System (start here)."* Deliver the template, set expectations that the first run should feel uncomfortable — a rejection is the system working, not a bug. CTA: run Agent 1 today, reply with what it rejected.
2. **Reframe the objection** — *"Why your last AI tool gave you generic junk."* Names "I already tried AI tools" directly and reframes it as a sequencing problem. CTA: haven't started? Here's the template again.
3. **Show the chain working** — *"What happens when Agent 2 gets a weak handoff."* A concrete before/after: vague input rejected, refined input accepted, clean handoff to the next agent. CTA: where are you in the chain? Reply and get pointed to the next agent.
4. **Name the ceiling honestly** — *"The template gets you 80% of the way there."* States plainly what the free system does and doesn't do (troubleshooting, extending the chain). No hard pitch. CTA: if you've run the full chain and want to go further, the workshop's below.
5. **Direct invite** — *"Ready to run this on repeat?"* Low-pressure invite to the workshop for people who already felt the "aha" from the template. CTA: see workshop details / grab a spot.

**Sales path:** the lead magnet is the actual conversion event — once someone's own input gets rejected by Agent 1, they've personally felt the core claim of the offer, which sells harder than any pitch. The sequence's job is just to keep them moving through the chain and then name the free system's honest ceiling. The workshop qualifies buyers for the $3K–10K done-with-you Sprint.

## What The Creator Must Show On Screen To Be Credible

- One agent (Positioning) built live and in full — not summarized, not "here's one I made earlier."
- A real, visible reject-then-refine moment on a generic output — this is the single strongest credibility beat in the video.
- The dependency chain shown visually — one agent's exact output being referenced or pasted as the next agent's input, not just claimed in narration.
- A real before/after: the one-line starting idea next to all five finished artifacts, with zero placeholder text anywhere on screen.
- Real, specific content in the offer formula on screen — never a bracket like "[niche]" left unfilled.

## What To Remove Because It Feels Generic

- Any framing of the agent team as a novelty ("look what Claude Code can do") instead of anchoring every step to a revenue decision.
- Lengthy setup/installation/prompting mechanics on screen — compress or cut entirely; the audience needs judgment shown, not configuration.
- Placeholder or vague output text ("[niche]," "your audience," "an outcome") appearing anywhere on screen — this is the exact "AI slop" signal the audience already pattern-matches to.
- Describing the workshop as "the real version" of the free template — reframe as extending the chain, never as revealing the free system was incomplete.
- Using "generic" as a description of the *viewer's* input anywhere in the follow-up emails — it's the system's rejection language, not a shame trigger; using it that way breaks the "helpful, not pushy" mandate.
